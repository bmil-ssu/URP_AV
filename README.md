# URP_AV
URP - Autonomous Driving

 #프로젝트 소개 및 연구 내용
본 URP를 통해 자율주행 차량의 의사결정 전략 구축 및 심화 모델 학습 프레임워크 전반을 체계적으로 경험할 수 있습니다.
- 환경 구축: SUMO 기반 도로 시뮬레이션을 활용하여 비자율주행 차량 혼합 도로 환경 구축
- 자율주행 차량 인공신경망 학습:
   * 모방학습 (BC, DAgger, flow-matching based actor)
   * 오프라인 강화학습 (IQL, CQL, DDPG+BC)
   * 온라인 강화학습 (PPO, DDPG)
- 성능 개선: 하이퍼파라미터 튜닝을 통해 충돌률 5% 미만 달성 및 주행 보상(Reward) 극대화
- 평가 및 검증: 충돌률, 누적 보상 등 정량 지표 기반 모델 평가 및 주행 데이터 수집·분석
